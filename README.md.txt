# AI Voice Pro

Free AI Text-to-Speech Web App

## Features
- Convert text to speech
- Download MP3
- English + Hindi support
- Male/Female voices

## Setup

1. Install Node.js
2. Run:
   npm install
   npm start

3. Open:
   http://localhost:3000

## Deployment

- Use Render.com
- Add environment variable:
  GOOGLE_KEY = your JSON key
